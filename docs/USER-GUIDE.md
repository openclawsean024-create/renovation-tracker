# 使用說明 — 裝修進度管理平台

這份說明分成兩部分：**業者端**（設計公司、統包商，負責建立與維護紀錄）與**屋主端**（透過分享連結查看）。

開始前請先知道三件事：

1. 資料只存在你這台裝置、這個瀏覽器裡。清除瀏覽器資料、用無痕視窗、換瀏覽器或換裝置，紀錄都會不見，目前也沒有備份功能。
2. 分享連結未加密、無法撤銷。傳出去之後收不回來。
3. 這個版本一次只管理一個工程。

App 右上角的「使用說明」按鈕可以隨時打開重點摘要。

## 業者端

### 1. 建立階段與更新進度

1. 第一次開啟會有一個示範工程與七個階段（拆除、水電、泥作、木作、油漆、安裝、驗收），可以直接改成自己的。
2. 在「階段與工期」點「新增階段」，填名稱、狀態、計畫開始與結束日。日期要落在工程期間內。
3. 點階段列的「編輯」更新狀態。改成「進行中」會自動記錄實際開始日，改成「已完成」會自動記錄實際完成日。
4. 上方的「工程完成度」＝已完成階段數 ÷ 階段總數。
5. 點「時間軸」或往下看「工期圖」，可以看每個階段在日曆上的位置。
6. 刪除階段會先跳出確認。刪除階段時，該階段的驗收項目會一起刪除。

### 2. 上傳照片與看照片進度回報

1. 在「照片紀錄」點「新增照片」，選圖片檔（單檔 10 MB 以內），選分類（施工前／施工中／完工）、拍攝日，並選擇關聯的階段。
2. 「照片進度回報」會依階段順序列出每個階段的照片數、最新拍攝日，以及最新一張的縮圖與說明。
3. 沒有關聯階段的照片會歸在「未分類」；還沒有照片的階段顯示「尚無照片」。
4. 照片只存在本機，不會上傳到任何地方。拍照時請避開門牌、鄰居與住戶的臉。

### 3. 記錄成本預算

「預算追蹤」是業者自己的成本：每個項目填分類、名稱、預算金額、實際金額與付款狀態。實際超過預算時會顯示超支警示。這一區和下面的合約金額是分開的，互不影響。

### 4. 合約金額、收款與變更單

1. 在「合約與收款」點「編輯合約金額」，填對屋主的合約金額與已收金額（0 以上、最多兩位小數）。
2. 有追加或追減時，在「預算變更單」點「新增變更單」：填標題與金額，追減請輸入負數。可以選填關聯階段、材料與備註。
3. 新增後狀態是「待決定」，這時還可以編輯。
4. 屋主同意或不同意後，由你點「核准」或「拒絕」記錄下來，系統會記下當天日期。**決定後就不能再編輯或改狀態**，記錯的話請刪除後重新新增。
5. 只有「已核准」的變更單會加進「調整後總額」；「待決定」和「已拒絕」都不計入。
6. 「待收」＝調整後總額 − 已收。已收超過調整後總額時，會顯示「溢收」提示。

請注意：這裡的「核准／拒絕」是你在本機代為記錄屋主的決定，**不是屋主線上簽核，也不是電子簽章，不具契約或法律效力**。需要正式同意時，請另外留下書面或其他憑證。

### 5. 階段驗收

1. 在「階段驗收」找到要驗收的階段，點「新增驗收項目」，一項一項列出要確認的內容。
2. 現場確認沒問題就勾選該項目，系統會自動記下檢查日。取消勾選會清除檢查日。
3. 每個階段會顯示「驗收 x/y」（已通過／總數），「階段與工期」的階段列也看得到。
4. 如果階段已經標記「已完成」但還有項目沒通過，會出現文字警示提醒你。警示不會阻擋任何操作。
5. 驗收項目可以編輯或刪除，刪除前會先確認。

### 6. 師傅排程與保固

- 「師傅排程」：填工班名稱、電話、起訖日與提醒日。提醒日 7 天內的未完成項目會列在頁面上的提醒區。
- 「保固紀錄」：填項目、提供者、聯絡方式與保固起訖。30 天內到期與已過期的保固會有文字提醒。

### 7. 產生分享連結給屋主

1. 點「產生唯讀分享連結」。系統會把當下的資料做成快照、產生連結並複製到剪貼簿。
2. 對話框裡有兩個選項，**預設都不勾**：
   - 「包含工程地址」
   - 「包含聯絡方式（工班電話、保固聯絡方式）」
   需要讓屋主看到才勾選。勾選或取消後連結會重新產生，請再按一次「複製分享連結」。
3. 把連結傳給屋主。之後資料有更新，要重新產生一次新的連結，舊連結不會跟著變。
4. 連結未加密、無法撤銷，也不會過期。請只傳給需要看的人。

## 屋主端

### 1. 開啟連結

直接用瀏覽器開啟業者傳來的連結，不需要登入、註冊或安裝任何東西。頁面最上方會標示「唯讀分享模式」。

### 2. 看懂各區塊

| 區塊 | 看什麼 |
|---|---|
| 工程總覽 | 工程名稱、狀態、預計施工期間、完成度與各狀態的階段數 |
| 階段清單、工期圖 | 每個階段的狀態、計畫日期、實際開始與完成日 |
| 照片紀錄、照片進度回報 | 每個階段拍了幾張、最新拍攝日，以及照片的分類、日期與說明 |
| 預算摘要 | 業者提供的預算總覽 |
| 合約收款與變更單 | 原合約、已核准變更合計、調整後總額、已收、待收，以及每一筆追加減的標題、金額與狀態 |
| 驗收進度 | 每個階段已通過幾項、共幾項 |
| 保固摘要 | 保固項目、提供者、期間與剩餘天數 |

### 3. 限制說明

- 這是業者按下「產生連結」那一刻的快照，**不會自動更新**。頁面上有「快照產生時間」；想看最新進度，請業者重新產生連結。
- 連結裡**沒有照片原圖**，照片原圖只存在業者的裝置上。
- 你只能查看，不能在這個頁面修改資料、核准變更單或留言。變更單上的「已核准／已拒絕」是業者記錄的狀態，不是你在線上簽核的結果；如果和你的認知不同，請直接向業者確認。
- 頁面預設不會顯示工程地址與聯絡方式，除非業者在產生連結時選擇放入。
- 連結未加密，任何拿到連結的人都能看到內容，請不要轉傳給無關的人。
- 如果頁面顯示「無法開啟分享連結」之類的錯誤，通常是連結被截斷或複製不完整，請業者重新傳一次。
