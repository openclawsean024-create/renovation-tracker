# 裝修進度神器 — PRD v3.0.2 等級規格書

> 建立日期:2026-09-19 · 對齊 SPEC v3.0 契約

## §1 產品概述

### 1.1 問題陳述
室內裝修進行中：(1) 屋主與設計師/工班進度不同步，常有「師傅說做了但屋主看不到」(2) 預算超支沒人提醒 (3) 完工後保固紀錄散落。本案提供「工程進度追蹤 + 照片記錄 + 預算管理 + 客戶查看 + 保固紀錄」。

### 1.2 目標使用者
- **Primary — 屋主**：付錢但不在現場，需要看到進度
- **Primary — 設計師**：管理多案，要對客戶交代
- **Secondary — 工班師傅**：上傳今日進度照片

### 1.3 核心價值主張
> 一個 dashboard，屋主、設計師、工班都看得到同樣的進度。

### 1.4 Non-Goals
- ❌ 3D 建模
- ❌ 真實金流（訂金/尾款）
- ❌ 監工直播

---

## §3 FR

- FR-001: 工程進度看板（多階段 / 甘特圖）
- FR-002: 照片記錄（before / progress / after，含時間軸）
- FR-003: 預算追蹤（合約 vs 實際，紅綠燈警示）
- FR-004: 客戶查看（唯讀連結，不用登入）
- FR-005: 師傅排程（時程表 / 提醒）
- FR-006: 保固紀錄（完工後 1 年）

## §4 NFR

- 照片 < 5 秒載入
- 支援大量照片（IndexedDB）

## §5 技術棧

- Vite + React 19 + TS strict
- IndexedDB
- Cloudflare R2 / S3 相容儲存
